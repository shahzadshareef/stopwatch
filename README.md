A simple and responsive Stopwatch Web Application built using HTML, CSS, and JavaScript.

Features
Start the stopwatch
Pause the stopwatch
Reset the stopwatch
Accurate time tracking
Simple and user-friendly interface
Responsive design
Technologies Used
HTML5
CSS3
JavaScript
Project Purpose

This project was created to practice JavaScript logic, DOM manipulation, event handling, and time-based functions.
